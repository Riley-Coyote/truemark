- paragraph: Quality
- heading "Quality, documented." [level=1]
- paragraph: Every lot moves through the same controlled path — from sourcing to release — and every step leaves a record you can read.
- paragraph: Process
- heading "From source batch to released vial" [level=2]
- text: STEP 01
- generic: Sourcing
- paragraph: Raw material is purchased against a written specification, with the supplier batch number recorded.
- text: STEP 02
- generic: Receipt & quarantine
- paragraph: Incoming lots are logged, assigned a TrueMark lot number, and held in temperature-controlled quarantine.
- text: STEP 03
- generic: Independent testing
- paragraph: Samples are sent to a contracted laboratory for HPLC purity, MS identity, endotoxin and sterility testing.
- text: STEP 04
- generic: CoA review & release
- paragraph: Results are reviewed against specification. Only approved lots are released; the CoA is published to the lot record.
- text: STEP 05
- generic: Cold-chain storage
- paragraph: Released vials are stored at −20 °C and shipped with temperature control to institutional addresses.
- paragraph: Release specification
- heading "Every lot is tested against the same bar" [level=2]
- paragraph: A lot that misses any specification is rejected and never enters released inventory. The full result set for each lot is published on its Certificate of Analysis and retrievable by lot number.

- paragraph: Records
- heading "What we keep on file for every lot" [level=2]
- generic: Batch record
- paragraph: Supplier batch number, receipt date, quarantine log, and assigned TrueMark lot number.
- generic: Certificate of Analysis
- paragraph: Full laboratory result set for the lot, published to the lot record and retrievable by lot number.
- generic: Retained samples
- paragraph: Vials from each lot are retained at −20 °C for re-testing if a question is ever raised.

- paragraph: Which lots shipped where and when — so any lot can be traced forward as well as back.
